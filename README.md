# Resume

This project contains my resume, written using the [Typst](https://typst.app/) typesetting system.

## Structure
- `resume.typ`: The main Typst file that defines the layout and pulls in data.
- `data_fr.typ`: Contains the personal data and content for the resume in French.
- `img/portrait.jpg`: Placeholder for a portrait image.

## How to Compile

To compile this resume, you need to have Typst installed.

1.  **Install Typst:** Follow the instructions on the [Typst website](https://typst.app/get-started/).
2.  **Compile:** Navigate to the project directory in your terminal and run:
    ```bash
    typst compile resume.typ
    ```
    This will generate `resume.pdf` in the project directory.

## Customization

You can customize the content by editing `data_fr.typ` and adjust the layout or styling in `resume.typ`.
